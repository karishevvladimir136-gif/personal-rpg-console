## Integrated bounded decisions

- Migration 14 adds schema-3 run association without expanding schemas 1/2. Eligible preparation uses stable configured schema-2 checkpoints; legacy saves remain readable/loadable and can produce a new eligible checkpoint after configuration. Historical run state is never invented.
- Prepared runs start with head revision 0. Every explicit continuation claims a branch-local lease, including continuations of a running run. Exact claim/commit receipts survive interruptions; a replaced lease rejects the earlier callback. A committed result is projected from its original coherent checkpoint with current privacy restrictions; a normal run read shows current history separately.
- Deterministic intervals are at most 60 fictional minutes, within a requested horizon of at most 43,200 minutes and 32 coherent continuation checkpoints. A zero-time no-op has no new manifest/version. Work-limit/resolver/agency/knowledge/unsupported pauses preserve the previous coherent head.
- SQL independently derives the accepted World schedule transition from the exact detached rows. Its write allowlist is only the World foundation revision/state, runtime revision/explicit time, and new typed World Events. Inherited Wave 4 loop state, resources, inventory, progression and receipts remain unchanged. Typed action consequences outside this schedule subset pause rather than being dropped or partially applied.
- The active Save epoch is never a detached authority. A private `{timelineId, epoch: 1}` compatibility value exists only inside the existing pure World/Memory transport contracts; the complete detached run fence authorizes persistence. Runtime adapters explicitly do not constitute a complete DM source and never call providers.
- Exact source/version restrictions and positive Actor knowledge precede existing Memory ranking and limits. Public checkpoint DTOs exclude private titles, diagnostics, source bundles, raw prompts and authority fields. Source appends serialize with run writes using the existing owner/canon lock vocabulary, even after the live campaign switches to a different binding basis.
