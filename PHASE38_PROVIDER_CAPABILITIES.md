# Phase 3.8A — provider capability / evidence matrix

> **Historical research snapshot — superseded as current status by the [final Phase 3.8B architecture record](PHASE38B_ARCHITECTURE_FREEZE.md).** The original dated body below is retained for provenance. Its proposed/not-authorized/untested statements describe that earlier checkpoint, not current experiment status. All four generation slots are now consumed; no additional 3.8B experiment or provider call is authorized by this document.

**Official public documentation checked 2026-09-19.** This is an offline research snapshot, not measured output quality, a procurement decision or production approval. “Documented” means supported by the linked official source; “unknown” means not established by this review, not necessarily impossible. Availability to this owner's account, current entitlement and real billing remain untested. Vendor latency/quality claims are not our results. No authenticated provider requests, generation, weights downloads or credentials were used.

Different products solve different problems. Persistent world assets, navigable generated video and simulation-ready objects must remain separate capabilities. No overall provider score is meaningful. [Architecture](PHASE38_SPATIAL_RUNTIME.md) defines the authority boundary; [3.8B](PHASE38B_LIVE_PROTOCOL.md) proposes only four paid jobs after separate approval.

## Cross-provider conclusions and verification boundaries

These are design inferences from the evidence, not provider benchmark results:

- Start with explicit capability discriminators and versioned assets/bindings. There is no common editable persistent-world or articulation contract across these families.
- Marble is the clearest documented hosted-world candidate; fal offers a small older-world compatibility probe and a current object API. HY-World 2.x hardware and Seed3D's unverified endpoint/price should not force extra infrastructure or speculative paid calls.
- Private-world flags and server-held keys do not prove safe source handling. Review account terms, retention, training settings and subprocessor paths before any separately authorized real data. Fal's [terms](https://fal.ai/legal/terms-of-service) and [privacy policy](https://fal.ai/legal/privacy-policy) apply alongside model terms; no zero-retention guarantee is claimed here.
- Browser/WebGL performance, physical iPhone/Safari, exact output geometry, binding stability, collision quality, persistent asset availability and owner account access remain unverified for every candidate. Generated physics/articulation never enforces RPG rules.

This matrix contacts only public official documentation. It does not contact classifier.dev, OpenRouter, GLiNER or Vercel Workflows. No Phase 3.75 experiment is reopened. Provider facts/prices must be rechecked before a separately frozen 3.8B authorization; changed facts pause and revise the proposal, never silently change an authorized run.
