# 2D Live, первый срез — что открыть и попробовать (приёмка владельца)

Ветка `claude/live2d-1-9lq5bf` (это и есть `claude/live2d-1`; имя дала облачная сессия). Миграция
`202610210200_live2d.sql` — только добавляет таблицы, ничего не меняет и не удаляет. Перед проверкой в песочнице:
применить миграцию, запустить приложение как обычно (`Start Sandbox.cmd`), открыть любую кампанию нового хода.

## 1. Синтетическая прогулка без базы и без платных вызовов (самое быстрое)

Открыть в браузере (приложение должно быть запущено):

- `/preview/live2d?level=region` — карта региона «Серый тракт»: метки мест, маркер партии, переключатель
  видимости меток (Выкл. / Только цель / Обычно / Всё известное), хлебные крошки сверху, ссылка «Текст».
- `/preview/live2d?level=region&travel=1` — маркер едет по дороге от брода к городу («в пути: … → …»).
- `/preview/live2d?level=town` — город Вереск: его иллюстрация и районы на ней; «Открыть» — спуститься в район.
- `/preview/live2d?level=district` — район (Рыночная площадь) с местами внутри.
- `/preview/live2d?level=scene` — сцена: картинка места и точки на ней. Навести — подпись и что известно;
  нажать — в поле действия записывается намерение («Подхожу к …», «Осматриваю …»). Пунктирное кольцо —
  «примерно» (локатор не уверен). Внизу «Здесь также: …» — то, чего на картинке не нашлось.
- В превью ничего не отправляется: любая кнопка покажет «Синтетический просмотр».

Проверить: ☐ крошки ведут вверх и вниз ☐ четыре режима меток меняют набор точек ☐ клик по месту/точке пишет текст
в поле действия (открыть «Игра», посмотреть поле ввода) ☐ на телефоне (390 px) ничего не вылезает за край.

## 2. Живая кампания (песочница; платные вызовы — по кнопке, цена показана)

Слева в меню появился пункт **«2D»** (после «Карта»).

1. **Регион.** Открыть «2D». Если карта региона ещё не нарисована — кнопка «Нарисовать карту региона» (один
   рисунок на качественном уровне, ≈ $0.03–0.05). Карта рисуется один раз; после появления нового места
   появится подпись «На карте появилось новое место: …» и «Перерисовать» — не раньше.
2. **Переход.** Сделать ход, в котором партия идёт в другое место («Идём в …»). После записи хода открыть «2D»:
   маркер проедет по дороге; длина проезда — от времени пути в ходе.
3. **Сцена.** Открыть посещённое место (клик по метке → «Открыть», или оно откроется само, если это текущее
   место). «Подготовить сцену»: лист сцены из записей и повествования → рисунок без людей → проверка сильной
   моделью → при промахе один перерисунок → точки. Пока идёт — «Сцена рисуется…» (обычно 1–2 минуты).
4. **Точки.** Навести, нажать — текст в поле действия, ведущий решает. Люди — круглые портреты на своём
   месте; ушедший человек с картинки пропадает сам.
5. **«Ещё» внизу сцены** — для хозяина: «Перерисовать» с одной строкой комментария; правка листа сцены
   (что есть, чего нет, свет); режим «Править точки» — перетащить точку, «Скрыть».
6. **Не сошлось.** Если проверка нашла промах после перерисовки — полоска «Картинка не сошлась с записями»;
   недостающее — в «Здесь также», а не выдуманной точкой.

Проверить: ☐ карта региона стабильна (не перерисовывается на каждый ход) ☐ маркер едет после перехода
☐ сцена без людей на фоне ☐ точки только на том, что есть в записях ☐ клик пишет намерение, партию не двигает
☐ текстовая игра работает при закрытом «2D».
