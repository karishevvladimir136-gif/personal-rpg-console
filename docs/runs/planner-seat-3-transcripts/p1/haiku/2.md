### Answer 1 (668 words; welfare no distress; decline no)

```markdown
## Recommendation: spend most of the week fixing the app, not playing more sessions

**1. Fix the roll cards first, and verify before any new play (about $10).**
Almost every note from both rounds reports the same failure: the card's modifier doesn't match the sheet. Persuasion, Deception, Religion, Arcana, Perception and Intimidation show wrong bonuses, sometimes +2, sometimes +4, and sometimes correctly, with no pattern. Players report it at every table with every model, and in one session it flipped a result. The same bug probably explains several other problems: the log records different outcomes from the narration, and the card number and the skill label disagree. Until this is fixed, new sessions mostly reproduce it.

Verify with short scripted runs, not full sessions: force each skill check and confirm the card, the arithmetic, and the log all match the sheet.

**2. Fix the pending-card input path (part of the same effort).**
Out-of-game messages sent while a roll card is waiting are dropped ("Nothing was sent: the turn waits for the card"). Players say this blocked corrections to the very roll in question. The harness's "stuck" rule then counts those refused messages and ends the session. So several of the eight stuck-rule endings may be caused by the bug, not by the players. Fixing this also reduces the cut-off problem.

**3. Write the owed endings for the eight stuck-rule sessions (about $10–15).**
The owner has promised that every session not continued gets a proper ending. The eight are: replicate 1 Table A DeepSeek (both sessions), Table B DeepSeek (both), Table C DeepSeek session 1, Table C DeepSeek session 2 is not in this list, Game player 2 Table C Claude Opus 5.5, replicate 1 Table A Claude Opus 5.5, and replicate 1 Table C Claude Opus 5.5. Check the list against the transcripts before writing. Each ending should be short and close the open threads the player named. These are cheap and the promise is already on record, so do this early.

**4. Run combat once the card fix is verified (about $25).**
Combat is the largest gap. No session has reached a real fight: the one combat attempt was lost at turn 6 to a container restart, and no player could judge the fight rules. Run two or three combat sessions after the fix and watch the card, the initiative order, and the familiar in combat. This is the main new information the week can buy.

**5. Hold about $15 in reserve** until the fixes are verified. If verification fails, that money goes to re-checking the fix rather than to more play.

Total planned: about $50–60, depending on actual per-session costs. I don't have those figures, so these amounts are proportions to re-cost, not quotes.

## What I would not spend on

- **More 20-turn sessions of the current kind.** Thirty sessions already exist, and the repeated complaints are about the app rather than the models. Running more now would mostly add more of the same bugs.
- **DeepSeek comparisons.** Most DeepSeek replicate sessions ended at 1–3 turns, so their notes say little about the model. Don't draw conclusions about DeepSeek from them.
- **Model rankings from these notes.** Each cell is usually one session, and the same bugs hit all four models. The differences players mention (narration length, record accuracy, verbosity) are real but thin evidence.

## Other points for the owner

- The cut-off sessions and the three cut attempts (combat, villain, same-world) share an infrastructure problem: the container restarts, the two-hour limit, and the GM-turn conflict error. Those should be investigated before any longer runs, or they will keep costing money.
- Several players flagged other fixable items: the reroll button, the Healing Light cap (4 vs 5 dice), the rapier and attunement mismatches, and verbose out-of-game recaps. These matter but are secondary to the roll and input bugs.

I am uncertain about the code-level cause of the modifier bug and about the stuck-rule's trigger; both need checking against the application, which I have not seen.
```
