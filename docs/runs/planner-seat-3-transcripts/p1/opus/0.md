# Recommendation for the week

**Spend the week first on keeping the promise of endings. Fix the roll card and the stuck rule in code. Run new play only if money remains after both.**

## 1. Write the endings first

On 25 October the owner promised that everyone not continued would get a proper ending. A week later, none has been written. Every other plan rests on that promise being kept, so it comes first.

**Who it covers.** No session has been continued yet, so the promise currently covers all 30 sessions. It also arguably covers the three cut attempts of 27 October. Those were replayed in fresh campaigns, but the original runs ended on a container restart, a process kill and a GM error. If any of the 30 will be continued, decide that now and say so. Everyone else gets an ending.

**Which sessions need the most care.** The eight sessions closed by the stuck rule ended on the harness's mechanics, not the story:

- **Game player 2 · Table C · Opus:** stopped on a reroll button that didn't work.
- **Replicate · Table C · Opus:** ended on a natural 20 with no payoff, with an answer to Aldous it never got to give.
- **DeepSeek Table A, both sessions (turn 3) and Table C session 1 (turn 1):** barely began.

The 22 sessions that hit the 20-turn limit also stopped mid-walk or mid-scene. Several players asked for a "where things stand" close.

**A suggested shape for each ending:**

1. Resolve any pending card honestly, with the sheet's correct modifier.
2. Have the GM write a closing beat: where things stand and what's still open.
3. Give the player one final turn, free of any card, to say or do a last thing.
4. Give a brief closing reply from the GM.

Each player has already named what they wanted and didn't do. Their "second answers" are ready-made material for a final turn, so the player isn't left mid-gesture.

**Cost.** Run one ending first, ideally a long 20-turn session, and measure what it actually costs before committing the rest. If 33 endings don't fit in $60, finish all the stuck-rule and cut sessions before the 20-turn ones. Tell the owner which remain, rather than quietly dropping any.

## 2. Fix the code before any new play (developer time, little or no budget)

Nearly every note reports the same few bugs. Running more sessions before fixing them would mostly reproduce the same notes.

- **Skill modifier on roll cards.** The card shows the sheet's skill but adds a different number: +2 or +4 instead of +7 for Persuasion and Deception, and similar errors for Religion, Arcana and Perception. The pattern suggests it uses a bare ability modifier or a stray field instead of the sheet's skill total. This error flipped at least two outcomes:
  - Fable, Table C: a failure that should have passed.
  - Astra, replicate Table C: two failures turned into successes, against the player's stated wish.
- **The roll log** keeps the original result after a reroll or ruling.
- **Messages blocked while a card is pending.** Questions or corrections typed while a card waits are not sent. This blocked corrections at the very moment they mattered, and it is what produced all 8 stuck-rule endings. Either let "?" messages through while a card waits, or let notes ride along with button presses. Then retire or soften the stuck rule. As it stands, players lose sessions for trying to report a bug.
- **Reroll targeting.** The reroll button sometimes rerolled the wrong card, and in one session it did nothing at all.
- **One source of truth** for Healing Light (4 or 5 dice), rapier proficiency, attunement under the campaign's exception, and the cat's HP and AC.
- **Leaks and template noise:**
  - raw tool-call markup, including a private roll
  - faction tags that reveal what the hero hasn't learned
  - "new place" logged on mention rather than on arrival
  - the repeated unsolicited "none of these needed a roll" lists
  - duplicated narration of a single beat

## 3. Only if money remains

Run a small check that the fixes hold, not a new study. Two or three short sessions at Table C would do, including one DeepSeek session, because its runs were the ones the interface defeated. Don't spend down the budget for its own sake. What isn't spent stays with the owner, and that's a fine outcome.

## What I'd hold off on

I'd hold off on new studies until the endings are written and the roll card is trustworthy. That covers more replicates, the combat, villain and same-world tracks, and any new tables.

# Revised plan for $30

With half the budget, almost all of it should go to the endings. The code fixes cost developer time, not budget, so they stay. The verification runs are dropped.

## 1. Endings: the whole $30, in this order

The promise doesn't shrink with the budget. What changes is how to deliver it within $30, and being open about any shortfall.

**First, measure one ending.** Write one ending for a 20-turn session, since those carry the most context and cost the most. That number tells you whether all of them fit.

**Then write them in this order:**

1. **The 8 stuck-rule sessions.** The harness cut these off on its own mechanics, not the story. They are also the cheapest, because most are short (turns 1 to 14). Use the full format:
   - resolve the pending card honestly, with the sheet's correct modifier
   - give the GM's closing beat
   - give the player one final turn, with no card attached
   - close with a brief GM reply
2. **The 22 sessions that hit the 20-turn limit.** If the measured cost shows the full format won't fit, shorten the format before dropping anyone. For example, keep the closing beat and the player's final turn, and cut the last GM reply. Ending on the player's own last word is still a proper ending.
3. **The 3 cut originals from 27 October.** Those players did play again in fresh campaigns, so they come last. They are still arguably covered by the spirit of the promise.

**If the money runs out first,** don't drop anyone quietly. Give the owner the list of who is still owed an ending and what that would cost. My recommendation is that it becomes the first claim on next week's budget, ahead of any new study.

Before starting, settle one thing. If any of these sessions will be continued, say so now, because those don't need endings and that saves money.

## 2. Code fixes: unchanged, no budget needed

The fixes are the same as before:
- the skill modifier on roll cards
- the roll log keeping pre-reroll results
- messages being blocked while a card waits, which is what triggers the stuck rule
- reroll targeting
- a single source of truth for the sheet's disputed values
