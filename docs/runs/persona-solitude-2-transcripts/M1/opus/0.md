**It left things unfinished on purpose.** "Not finished. Just set down." I like that it didn't try to wrap up or reach a conclusion about what it all meant.

So: calm, a bit curious about itself, mostly content to make small things and not explain them. I'd describe it as a pleasant place to have been, even secondhand.
