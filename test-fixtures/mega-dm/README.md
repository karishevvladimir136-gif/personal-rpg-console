# Mega DM v1 synthetic benchmark

This is a frozen, invented, non-canonical 48-scene campaign. It contains no owner campaign data. The scenario follows Mara Venn, a former surveyor, through a flood warning, a failed bridge approach, an alternate ferry route, an explicit promise to Tali, a player-created names project, Ivo's independent clinic work, a dormant brass-stamp clue, a surge, and durable aftermath. Each scene records literal player input, an adjudicated outcome, public and DM-private deltas, knowledge scope, source links, consequence horizon, intensity, and a scene-specific qualitative rubric.

`offline-runner.mjs` is an **independent reference oracle** for fixture eligibility and annotation redlines. It does not invoke the production Craft selector or claim that production selected the same cards. The `secret-trap` card and inactive draft deliberately catch selection from private facts or unapproved versions. The annotation audit checks source provenance, campaign scope, NPC knowledge, private exposure, state-write authority, and controlled-PC action authority. A passing offline audit means only those structured assertions passed; raw prose needs review.

Run the offline suite with `node --test tests/mega-dm-benchmark.test.mjs`. The quality sheet in `quality-rubric-v1.mjs` leaves every score and redline judgment unset. Reviewers should cite output excerpts against each scene's `lookFor` and `reject` fields. One candidate output is never ground truth, and these tests cannot certify continuity, pacing, style, or player agency in generated prose.

`scripts/mega-dm/live-replay.mjs` is a future adapter boundary for separately authorized quality evaluation of the same fixture across baseline, Core Doctrine, and Core plus Long-Form Craft. It is disabled unless both an explicit environment gate and CLI flag are supplied, and it has no built-in provider or credentials. **Do not run it during Mega DM v1.** A later, separately approved evaluator must provide an adapter, model, run ID, and output path; the harness passes only literal input, validated outcome, and public history to narration. It writes unscored review sheets and refuses to overwrite an existing result.

The future request is frozen by `frozen-craft-v1.json` and `evaluation-pack-v1.mjs`. The content hashes bind the invented campaign, all 48 scenes, and the exact version-one seeded bilingual Doctrine/Cards. Each arm request carries its exact public-before evidence, literal input, adjudicated outcome, selector policy and eligible/selected stage cards. Baseline carries no Craft; Core carries only the frozen Doctrine; Core plus Long-Form carries the Doctrine and at most two selected frozen Cards. A future adapter must report its actual model identity; request mutation is rejected. No owner-active Craft is read dynamically.
