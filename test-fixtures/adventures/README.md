# Adventure Acceptance Set V1

These are three NEW synthetic scenario families, separate from the frozen Mega DM datasets: Low Letter, High Letter, and Merchant Vault. Each contains a complete isolated starting LoopContext, strict private object versions, exact references, a pinned synthetic World basis, and an explicit profile. Low and High Letter reuse only that immutable basis. Mutable campaign, timeline, entity, Item, Storage and event identities differ.

The manifest pins SHA-256 of the exact JSON bytes. build-fixtures.mjs is an offline, deterministic authoring utility; it uses existing fixture helpers and the bounded owner configuration planner. Fixtures have no prescribed action sequence, answer key, automatic quality score, or live-provider attempt. The 3–5 hour target is guidance rather than a forced timer.

Private contents/provenance and access policies are server authority. Public model context must use filtered public projection, never this complete authority JSON. The Merchant Vault uses one coarse building Location and explicitly places the merchant downstairs; this leaf cannot infer room awareness or update guard knowledge from noise. Keys and agreement grants require recorded positive authority; possession of a key is not assumed.

Focused tests prove deterministic leaf planning, profile integrity, scope filtering and finite Item consequences. Their disposable in-memory commit double does not prove SQL atomicity, live save/import/new-campaign lifecycle, normal TurnStore integration, provider quality, or arbitrary-language adjudication. Those require the Lead's normal runtime and lifecycle harness. Frozen Mega DM fixtures and evidence are untouched.
