## Final bounded implementation decisions

- Existing immutable Library Scenario versions carry optional schema-1 composition metadata: literal premise, exact saved basis, original proposal, owner review/edit provenance, pinned profiles and usage. There is no new proposal table. Approval produces the existing Scenario/Divergence records and calls D1 preparation. The browser's `interpret/edit/approve/retry_interpret` API cannot submit a commit or an authority record.
- New model-backed inputs use `single-model-world-v1` and one optional `world.resolve` profile. Historical D1 inputs omit that profile and retain `deterministic-world-v1`; the old meaning is unchanged. Existing World Resolver v1 remains intact; its bounded simulation mode uses `world-resolver-simulation-v2`, with a schema-2 settlement proof.
- Migration 15 creates no new table or save family. Existing private Lab commands gain durable model-request/model-result stages; immutable Scenario triggers, exact-source preparation, detached owning-validator adapters and commit checks extend the accepted authorities. Historical manifest versions/hashes are not rewritten.
- The SQL consequence adapter reads exact manifest rows for the existing Wave 3 validator; ordinary live callers retain the original wrapper. SQL independently checks pinned profile, approved assumptions, offered work and recorded proposal, derives the allowed state writes, then uses the original atomic vault/manifest/CAS/receipt transaction. Test-injected failures after row writes and after head updates roll back all effects.
- Admitted generative effects are resource spending, inventory consumption, supported conditions, Actor relocation and observation, within existing capabilities and known state. Direct observation/travel authority requires a current positive-known fact with no indirect source chain; the normal Memory path can still use validated chains for reasoning. No new reward, wallet, commerce, Actor or prose authority is introduced.
- Composition source facts are conservatively limited to current public facts with exact evidence and no epistemic uncertainty. Positive Actor knowledge is required for character evidence. Owner text never becomes an external fact. Unsupported relationship/rule changes, player-controlled decisions, missing knowledge and consequential ambiguity cannot bypass review.
- Saved world policy is displayed read-only, preserving existing overdue-reconciliation authority. A different policy needs a new campaign save. No controlled-PC takeover is offered. Existing 60-minute segments, 32-checkpoint budget and finite horizon remain; mandatory work is paused rather than truncated.
- Model request/result persistence precedes settlement. Lost responses after durable recording replay exact results. Original public receipts use usage only through that receipt's revision, never later calls. Network/billing exactly-once is not claimed when a response was not recorded or transport attempts overlap. No fallback, automatic background work or second summary call is added.
